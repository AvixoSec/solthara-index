# SOLTHARA — VECTOR v2

Доработка выбранного VECTOR: графитовый исследовательский интерфейс с лаймовым акцентом, полной базой моделей и подробными досье. Это рабочий статический React-интерфейс, а не картинка или ограниченный макет.

## Как посмотреть

**Быстрее всего:** откройте `Solthara-VECTOR-v2.html` в современном браузере. CSS, React и все данные уже внутри файла. Установка и локальный сервер не нужны. JavaScript должен быть включён.

**Версия для сайта:** распакуйте весь архив и откройте `index.html`. Рядом должны оставаться `assets/` и `all-configs.js`. Эту структуру можно разместить на статическом хостинге, включая GitHub Pages.

**Для редактирования:** основной компонент — `src/Vector.jsx`, стили — `src/vector.css`, запуск — `src/main.jsx`. Сам `.jsx` браузер напрямую не выполняет: для просмотра используйте готовый HTML.

## Что добавлено

- Все **101 полная запись** из предоставленного архива вместо сокращённых восьми полей первой версии.
- Клик по названию или строке открывает досье. Кнопка с глазом обновляет правый инспектор.
- Восемь вкладок: Overview, Architecture, Math & config, Training, Benchmarks, Theory, Sources, Raw JSON.
- Исходные ссылки на архитектурные изображения, просмотр с увеличением 100–300%, сброс масштаба и отдельное закрытие просмотрщика.
- Галерея с названиями моделей и изображениями; табличный режим сохранён.
- Отдельно показаны configuration, advertised, native, trained, tested и API context. Это разные утверждения источника, а не одна гарантированная длина контекста.
- Поля обучения, заметки, источники, исходные confidence/status. Значения inferred, mixed и undisclosed не превращаются в verified.
- Матрица из 19 полей, 15 исходных исторических вех и восемь разделов теории.
- Поиск, фильтры, сортировка, пагинация, сравнение до трёх моделей, выгрузка полных выбранных записей.
- Мобильная навигация, внутренний скролл широких таблиц, клавиатурный фокус и Escape. Ctrl/Cmd+K открывает поиск; в досье вкладки переключаются стрелками, Home и End.

## Важно об изображениях

В предоставленном ZIP **нет файлов изображений**: оригинальный сайт использует внешние ссылки на `sebastianraschka.com`. Эти ссылки сохранены без замены на выдуманные фотографии.

Для оригинальных изображений требуется интернет и доступность внешнего источника. Если файл не загружается, интерфейс показывает явно подписанную **упрощённую карту конфигурации**, построенную из полей выбранной модели. Это не копия исходной картинки и не полная техническая схема. Переключатель Local map позволяет выбрать её вручную. Кнопка Open original ведёт к исходному URL.

Оригинальные внешние изображения не были скачаны и визуально проверены при сборке: сеть в среде проверки недоступна. Проверены состояние ошибки, локальные карты, увеличение и успешная ветка загрузки через отдельный синтетический тестовый ответ. Тестовое изображение не включено в сайт.

## Данные и ограничения

Источник: предоставленный архив `solthara-index-main.zip`, проект https://github.com/AvixoSec/solthara-index.

- Версия набора данных: **2.4**; его timestamp: `2026-09-01T09:58:27.088704Z`.
- `all-configs.js`, `all-configs.json` и `models.yml` сохранены без изменения содержимого. JSON и JS содержат один и тот же объект данных; контрольные суммы — в `source-integrity.json`.
- Старый интерфейс сохранён без изменений в `index-original.html`; исходный README также сохранён.
- Даты, описания, оценки обучения, confidence, бенчмарки и ссылки перенесены как утверждения исходного набора данных. Независимый научный аудит не выполнялся.
- Это не живой рейтинг Arena. Отсутствующие бенчмарки остаются неизвестными, а не равными нулю.
- Сокращения K/M/B/T округлены для отображения. Точные исходные значения доступны в полях и Raw JSON.
- Для очень больших записей экранный Raw JSON ограничен 160 000 символами. Скачивание всегда содержит полную запись; это проверено и для самой большой конфигурации.
- Категории MoE, Dense и Hybrid могут пересекаться; например, гибридная архитектура может использовать MoE.

## Пересборка

Требуется Node.js 20+ и доступ к npm для первоначальной установки зависимостей:

```sh
npm install
npm run build
```

Сборка обновляет `assets/vector.js`, `assets/vector.css`, `index.html` и автономный `Solthara-VECTOR-v2.html`. Данные при этом не изменяются. Для обычного просмотра пересборка не нужна.

Компонент можно подключить к другому React-приложению:

```jsx
import Vector from './src/Vector.jsx';

// data — полный объект из all-configs.json
<Vector data={data} />;
```

## Проверки

Основной отчёт — `qa-report.json`, дополнительные взаимодействия — `interaction-qa.json`, выборочная проверка фактических цветов — `contrast-report.json`.

Проверены все 101 досье × 8 вкладок, полные выгрузки, поиск, фильтры, сортировки, сравнение, клавиатура и ширины от 320 до 1440 px. Основные экраны, диалоги, вкладки, мобильное меню, фильтры и пустые состояния дополнительно просмотрены визуально. Это не заявление о полной WCAG-сертификации или о доступности всех внешних ссылок.
