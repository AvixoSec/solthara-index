# Historical release evidence

The original QA reports, visual/interaction reports, release manifest and source-integrity assertions from commit `30a2ea0f117d37fc24a64f2eb4a69229d635169a` are preserved in this directory by the repair installer.

They are **historical assertions about the old snapshot**, not tests executed for the repaired version. Do not reuse their passing labels as current verification.

Current structural checks: `npm run validate`.
Current build output hashes: `audit/current-integrity.json`, generated by `npm run build`.
Per-record structural/provenance report: `npm run audit:data`.
Actual GitHub check results and browser tests must be reviewed separately.
